# 外部模型 / 子 Agent：名称理解接口（intel.json）

CyberCensus 不内置模型。你可以让任意一个模型或子 Agent 先把「用户输入」
理解成结构化结果，再由扫描器消费——模型只负责"理解与查询计划"，
**不直接判定资产归属**，所有候选仍走标题 / 证书 / 备案互证。

## 一、调用方式

```bat
:: 命令行
python cybercensus.py -n "中国移动通信集团四川有限公司" --intel intel.json

:: 界面：高级参数 → 理解结果JSON → 选择 intel.json
```

## 二、JSON 契约

```json
{
  "aliases": ["四川移动", "川移"],
  "queries": [
    "四川移动 网上营业厅",
    "四川移动 官网",
    "四川移动 招聘"
  ],
  "seed_domains": ["wap.sc.10086.cn"]
}
```

| 字段 | 含义 | 限制 | 扫描器怎么用 |
|------|------|------|--------------|
| `aliases` | 主体别名/简称 | 最多 10 条，每条 ≤50 字 | 加入名称互证；没有 `queries` 时也作为搜索词 |
| `queries` | 建议的搜索语句 | 最多 8 条，每条 ≤80 字 | 逐条执行搜索，结果进入原有候选池 |
| `seed_domains` | 候选域名（可含 URL） | 最多 20 条 | 作为候选参与验证；**不直接入锚点** |

> 模型输出的 `seed_domains` 只是"假设"。验证不通过（标题/证书/信用代码
> 对不上）就不会进入确认清单，也不会触发后续扫描。

## 三、子 Agent 系统提示词（可直接使用）

```text
你是 CyberCensus 的"测绘查询规划器"。用户会给你一个单位名称（可能是简称、
全称或带错别字）。你只输出一个 JSON 对象，不要输出解释、Markdown 或代码块。

任务：
1. 还原主体：推断全称、常见简称、所属省份、行业、上级集团（如能确定）。
2. 生成 3-8 条中文搜索语句，覆盖：官网、网上营业厅/预约挂号/办事大厅、
   招聘、采购招标、公众号/小程序、上级集团 + 省份。
3. 仅当你能确定该单位的公开品牌根域时，给出 0-10 个候选域名
   （例如运营商 10086.cn / 10010.com / 189.cn 的省级入口）。

硬性规则：
- 不要编造域名；不确定就给空数组。
- 不要输出任何资产归属结论。
- 不要建议绕过登录、验证码或访问控制。
- 输出必须是严格 JSON：

{
  "aliases": ["..."],
  "queries": ["..."],
  "seed_domains": ["..."]
}
```

## 四、示例

输入：`中国移动通信集团四川有限公司`

```json
{
  "aliases": ["四川移动", "川移", "中国移动四川公司"],
  "queries": [
    "四川移动 网上营业厅",
    "四川移动 官网",
    "四川移动 招聘",
    "中国移动 四川 采购招标"
  ],
  "seed_domains": ["wap.sc.10086.cn"]
}
```

扫描器会：用这些查询词补搜 → 把 `wap.sc.10086.cn` 作为候选去验证 →
标题/证书通过后锚定 `sc.10086.cn` → 再展开子域与被动源。

## 五、注意

- `intel.json` 里不要放账号密码、Token、客户数据等敏感信息；
- 模型/子 Agent 运行在你自己控制的环境里，本工具不会上传目标名称；
- 文件读取失败或格式错误只告警，不阻断扫描（自动回退到规则逻辑）。
